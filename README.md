# LoHan Barnes — Engineering Capstone Notebook

My digital engineering notebook for capstone class, built with [Astro](https://astro.build). It covers my capstone project, the WET Invention Challenge, past projects, resources, and a periodic blog.

The animation system, component structure, and visual design this site is built on come from [Antoine Wodniack's open-sourced portfolio](https://github.com/AntoineW/AW-2025-Portfolio) ([public.wodniack.dev](https://public.wodniack.dev)), used under [CC BY-NC 4.0](LICENSE.md). See [LICENSE.md](LICENSE.md) for the full notice and what was changed.

## Pages

- **Home** — bio, capstone goals, engineering interests, contact
- **Resources** — links and syllabus
- **WET Invention Challenge** / **Capstone Project** / **Past Projects** — placeholder pages, filled in as work happens
- **Blog** — periodic entries (`src/content/blog/`, one Markdown file per post)

## Getting started

```bash
npm install
npm run dev
```

`npm run build` builds the static site; it deploys automatically to GitHub Pages on push to `main` (see `.github/workflows/deploy.yml`).
